This Process OF making Brick From Raw materia to procution 

Step 1: कच्चा माल / मटेरियल (Raw Material)
(Image: step1.jpeg)
यह पेज ईंट बनाने के लिए आवश्यक कच्चे माल और उनकी लागत (Costing) के बारे में है।
फ्लाई एश (Fly Ash):
फ्लाई एश गाड़ि में आता है।
अलग-अलग पार्टी से, तो उसका टन (Ton) का हिसाब रहता है।
पैसे: जैसे कोई गाड़ि - 21 टन, 34 टन और...
Demo (उदाहरण): 21 \times 400 = 8400/- (यानी 400 रुपये प्रति टन)।
(600 = 12600/- भी लिखा है, शायद किसी और रेट का उदाहरण है)।
डस्ट / बजरी (Dust):
वो भी टन में आता है।
हिसाब: 24 \times 250 से 300 = 7200/- (लगभग)।
चुना (Lime):
35 टन, 15 टन, 20 टन।
वो भी 30 \times 7200 = 216000/- (शायद 7200 रुपये प्रति टन का रेट है)।
हाड़नर (Hardener):
ड्रम 230 लिटर का।
कीमत: 10,000 या 12,000 तक।
जिप्सम (Gypsum):
वो भी टन में आता है।
हिसाब: 35 \text{ टन} \times 2500 = 87500/-।
नोट: ये सभी कच्चा माल / मटेरियल हो गया। अब यहाँ से माल बना के ईंट बनेगा।
Step 2: लेबर और ट्रांसपोर्ट (Labor & Transport)
(Image: step2.jpeg)
यह पेज ईंट बनने के बाद मजदूरी और गाड़ी के भाड़े (Transport) के बारे में है।
लेबर खर्च (Labor Cost):
ईंट बनने के बाद उसे लेबर को पर डे (per day) देना होता है।
1000 ईंट का लेबर रेट: 550 - 600 रुपये।
हिसाब: अगर 1 दिन में 10,000 ईंट बनी \times 0.60 (60 पैसे/ईंट) = 6000 रुपये लेबर खर्च।
स्टॉक और बिक्री (Stocking & Sales):
अब ईंट बनने के बाद उनको स्टॉक करके रखते हैं।
उसके बाद उसको बेचने के लिए, पार्टी के पास छोड़ने के लिए गाड़ि में डाल कर भेजना पड़ता है।
तो गाड़ि का खर्च अलग देना पड़ता है।
नोट (ट्रांसपोर्ट रेट):
2000 ईंट एक गाड़ि में जावेगा।
उसके किलोमीटर (KM) या गांव देख कर उसका अलग-अलग रेट तय रहता है।
2000 ईंट का भाड़ा: 700 / 800 / 1200 / 1500 तक रहता है।
और छोटी गाड़ि का पैसा भी रहता है KM के हिसाब से।
Step 3: बिलिंग और मैनेजमेंट (Billing & Management)
(Image: step3.jpeg)
यह पेज बिक्री के बाद के हिसाब, बिल बनाने और स्टॉक मैनेजमेंट के बारे में है।
बिक्री रेट (Sales Rate):
उसके बाद पार्टी को 2000 ईंट का... 8500/- 9500/- 10000/- 12000/- अलग-अलग रेट वाला है (शायद क्वालिटी या दूरी के हिसाब से)।
कागजी काम (Paperwork):
गाड़ि के लिए चालान बनाना।
पार्टी के लिए बिल निकालना।
हिसाब-किताब (Accounting):
और टोटल मेरेको दिये कितना (Payment received)।
Month (महीने) में कितना ईंट बना।
कितना बिका।
और कितना अभी शेष (Stock) है।
ईंट के प्रकार (Brick Sizes):
मेरे पास 8", 9" और ब्लॉक में 16 \times 8 \times 6 का ईंट बनाता हूँ।
सारांश (Summary)
यह दस्तावेज एक ईंट भट्ठे का पूरा "Business Logic" समझाता है:
Step 1: कच्चा माल (राख, डस्ट, चुना, केमिकल, जिप्सम) खरीदो और टन के हिसाब से पेमेंट करो।
Step 2: मजदूर को ईंट बनाने का पैसा (550-600 रुपये प्रति हजार) दो और ईंट स्टॉक करो। फिर ऑर्डर आने पर गाड़ी से भेजो जिसका भाड़ा दूरी के हिसाब से लगेगा।
Step 3: ग्राहक को बिल दो (चालान काटो), पेमेंट लो और महीने के अंत में स्टॉक (बना-बिका-बचा) का रजिस्टर मेंटेन करो।

async function runSeeder() {
    await connectDB();

    const clearExisting = process.argv.includes('--clear');

    // Check if data already exists
    const existingUsers = await User.countDocuments();
    const existingItems = await Item.countDocuments();

    if (existingUsers > 0 && !clearExisting) {
        console.log('\n⚠️  Database already contains data!');
        console.log(`   Found ${existingUsers} users and ${existingItems} items.`);
        console.log('   Use --clear flag to clear existing data before seeding.');
        console.log('   Example: node scripts/seed.js --clear\n');
        await mongoose.disconnect();
        process.exit(0);
    }

    if (clearExisting) {
        await clearData();
    }

    console.log('\n🌱 Starting seed process...\n');

    try {
        const adminUser = await seedUsers();
        const categories = await seedCategories(adminUser._id);
        await seedItems(adminUser._id, categories);
        await seedVendors(adminUser._id);
        await seedWarehouses(adminUser._id);
        await seedPurchaseOrders(adminUser._id);
        await seedKilns();

        console.log('\n✅ Seeding completed successfully!\n');
        console.log('📋 Admin Credentials:');
        console.log('   Email: admin@brickerp.com');
        console.log('   Password: Admin@123456\n');

    } catch (error) {
        console.error('❌ Seeding failed:', error);
    } finally {
        await mongoose.disconnect();
        console.log('🔌 Database disconnected');
        process.exit(0);
    }
}

runSeeder();
